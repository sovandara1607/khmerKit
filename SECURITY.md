# Security Policy

## Supported Versions

The following versions of KhmerKit are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in KhmerKit, please do not open a public issue.

Instead, please report the vulnerability privately by opening a [Security Advisory](https://github.com/sovandara1607/khmerKit/security/advisories) on GitHub or emailing the maintainers directly.

Please include:
- A description of the issue and potential impact
- Steps or a minimal script to reproduce the vulnerability
- Any proposed mitigations or fixes

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a responsible disclosure and patch.
